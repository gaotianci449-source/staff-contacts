# 员工联系方式 · 网页版

给 iPhone 同事用的网页版，功能和安卓版「员工联系方式」一致，备份文件两边通用。

网址：https://gaotianci449-source.github.io/staff-contacts/

## iPhone 安装（一次就好）

1. 用 **Safari** 打开上面的网址（微信里点开不行，要先「复制链接」，再粘贴到 Safari）
2. 点屏幕下方的「分享」按钮（方框带向上箭头）
3. 往下找「添加到主屏幕」，点右上角「添加」
4. 以后从桌面上的「员工联系方式」图标打开

第一次打开需要联网，之后没网也能用。

## 拿到名单

1. 在安卓手机上：员工联系方式 → 交接备份 → 发送备份文件 → 发到微信
2. 在 iPhone 微信里打开这个文件 → 右上角「…」→「用其他应用打开」→「存储到文件」
3. 打开员工联系方式 → 交接备份 → 选择备份文件 → 选刚才存的文件 → 合并

## 从表格导入名单

交接备份之外，也可以直接导入 WPS / Excel 表格（xlsx 或 CSV）：导入 / 导出名单 → 导入员工名单 → 选表格。程序会自动找表头、工票号、姓名、电话、工种和在岗状态，默认只导入在岗的人，导入前先显示预览，对应关系不对可以手动改。

## 注意

- 数据只存在这台 iPhone 里，不会上传。删掉桌面图标或清空 Safari 数据，名单会没有，需要重新导入备份。
- 本仓库只有程序，不含任何员工数据。

## 更新网页后

改了 `index.html` 之后，把 `sw.js` 第一行附近的 `VERSION` 改一下（比如 `sc-v1` 改成 `sc-v2`），同事下次联网打开时会自动换成新版。
